# CitiRide Assets

`source/` contains the raw uploaded files exactly as provided.

The app uses the cleaned filenames in this folder:

- `citiride-logo.svg`
- `hero-citiride.jpg`
- `services-collage.png`
- `about-city.png`
- `review-person.jpg`
- `driver-waitlist.png`
- `rider-waitlist.png`
- `stellapeters.svg`
- `dorcasnwibe.svg`
- `ritasimon.svg`
- `waitlist-video-1.mp4`
- `waitlist-video-2.mp4`
- `waitlist-video-3.mp4`
- `waitlist-video-4.mp4`

The testimonial cards are built in HTML/CSS using the SVG avatars and direct video files. The older `testimonial-*.png` files are reference mockups only.

If a replacement image or video is needed later, keep the same cleaned filename and the frontend will pick it up automatically.
